## WebSearch (загрузить: `ToolSearch` → `select:WebSearch`)
Официальное описание: «Search the web. Returns result blocks with titles and URLs. US-only.»
**Как на самом деле (проверено ведущим 2026-11-23):**
- «US-only» ≠ «только англоязычные сайты». Русскоязычные запросы работают и возвращают .kz-домены
  (пример: запрос про кухни в Алматы вернул obyavleniya.kaspi.kz).
- Возвращает не только ссылки, но и **сгенерированный пересказ** найденного. Пересказ — это
  наводка, а не доказательство: он может смешивать страницы и делать выводы, которых на странице нет.
  Цитировать как факт можно только то, что пересказ явно привязывает к конкретному URL; при
  сомнении — открыть страницу (WebFetch) или пометить уровень доверия ниже.
- Длинные запросы из 6+ слов дают навигационный мусор (страницы-каталоги без содержания).
  Работает лучше: короткий широкий запрос 2–4 слова → затем сужение.
- `allowed_domains` — лучший способ прицелиться в конкретный источник (otzovik.com, 2gis.kz,
  vc.ru, kapital.kz, t.me и т.д.).
- `mode: "standard"` по умолчанию; `"extended"` — только если standard вернул мало/не то, или для
  нишевых/свежих фактов (2025–2026). Extended в разы дороже.
- После результатов инструмент требует «Sources:» со ссылками — в ваших файлах это раздел «Источники».

## Bash / curl — НЕ ИСПОЛЬЗОВАТЬ для веба
Проверено ведущим: исходящий прокси отклоняет (HTTP 403, `connect_rejected`) прямые запросы к
t.me, otzovik.com, youdo.com, 2gis.kz, krisha.kz, forumhouse.ru, vc.ru, tgstat.ru, duckduckgo, yandex.kz.
Это политика сети сессии, не ошибка TLS — обходить не пытаться, флаги curl не помогут.
Bash используйте только для записи файлов и дописывания tools.md.

## WebFetch (загрузить: `ToolSearch` → `select:WebFetch`)
Если доступен — открывает страницу и возвращает ответ на ваш вопрос о ней. Ведущий не проверял,
есть ли он у субагентов: проверьте сами через ToolSearch и запишите результат в журнал ниже.
Ожидаемые проблемы (гипотезы, подтвердите или опровергните):
- Instagram, Kaspi-магазин, 2GIS-карточки — часто рендерятся JS или закрыты от ботов.
- otzovik.com — может отдавать капчу; тогда опирайтесь на сниппеты WebSearch с `allowed_domains`.
- Telegram: публичное веб-превью канала — `https://t.me/s/<имя_канала>` (не `t.me/<имя>`).

## Правила цитирования
- У каждой находки — URL и дата публикации (или «дата не указана»).
- Уровень доказательности: A — цифры кейса; B — массовое наблюдение/голос клиента; C — мнение эксперта.
- Источник не из Казахстана — помечать «не КЗ».

### [Q2 manufacturers_offers, 2026-11-23] WebSearch — что сработало
- `mode: "extended"` + короткий коммерческий запрос («кухни от производителя Алматы бесплатный замер») впервые
  вернул реальные сайты фабрик (.kz) вместо агрегаторов. Standard по тем же темам — почти только olx/kaspi.
- `allowed_domains` со списком 3–9 доменов даёт выдержки по конкретным сайтам, НО при смешении доменов
  пересказ иногда ставит загадочные метки вида «(9-24, 2-46)» вместо URL — атрибуция к сайту неочевидна.
  Лучше 1–3 домена на запрос, если важна точная привязка цитаты.
- Пересказ сообщает «страница помечена как N days ago» — это метка индекса, а не дата публикации; использовать
  только как признак устаревшей акции.
- [Q5 expert_trends] WebSearch с allowed_domains=["t.me"] находит каналы, но пересказ склеивает цитаты разных
  каналов/статей в один абзац (одна и та же фраза приписывалась то С. Александрову, то «владельцу бизнеса» из КЗ-статьи).
  Даты постов Telegram пересказ не отдаёт. Атрибуцию таких цитат помечайте «вероятная».
- [customer_voice, 2026-11-23] WebSearch с `allowed_domains: ["reddit.com"]` падает с API Error 400 («domains are not accessible to our user agent»). Reddit недоступен совсем.
- [customer_voice] Слово «кухня» без уточнения в запросах к 2gis.kz/otzovik/irecommend возвращает рестораны и кафе. Пишите «кухонная мебель», «кухонный гарнитур», «кухня на заказ» + название фирмы/города.
- [customer_voice] С `allowed_domains: krisha.kz` приходят только объявления о квартирах, форумных обсуждений нет. Мамские форумы (baby.kz, mamasha.kz) ничего не вернули. Из КЗ-форумов ищется только vse.kz (домен vse.kz, не forum.vse.kz), и треды там в основном старше 2024 года.
- [customer_voice] Пересказ WebSearch по карточкам 2GIS даёт дословные фрагменты отзывов и рейтинги, но НЕ даёт дат отзывов. Рейтинг и число оценок у одной карточки расходятся между запросами (снимки разного времени). Иногда пересказ приходит на английском.
- [customer_voice] obyavleniya.kaspi.kz — это объявления продавцов, а не отзывы покупателей; голос клиента там не искать.
- [Q1 market_context, 2026-11-23] Пересказ WebSearch путает годы: цифры Energyprom «мебель +24,6%, Астана +53,1%» подал как «вероятно 2026», а уточняющий запрос с точными цифрами показал май 2023; статью tengrinews от 2024-03-18 в другом пересказе назвал «2020 года». Правило: любую цифру без явной даты перепроверять вторым запросом, где сама цифра вписана в query.
- [Q1] URL в выдаче может не совпадать с цитируемым периодом (NapoleonCat: URL /2023/03, текст «October 2026»). Цифру не из того URL помечать «атрибуция приблизительная».
- [Q1] Для цен (тенге/пог. м) mode "standard" возвращает только каталоги obyavleniya.kaspi.kz без цифр; mode "extended" дал сайты производителей с ценами — здесь extended оправдан.
